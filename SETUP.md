# VYADH GitHub Profile Pack

Profile repository: https://github.com/aayush-ethclhkr/aayush-ethclhkr

## Installation
1. Create a **public** repository named exactly `aayush-ethclhkr` (same as your GitHub username).
2. Upload `README.md`, the `assets/` folder and `.github/workflows/snake.yml` from this ZIP. Keep paths unchanged.
3. Commit to the repo's default branch (`main`). The terminal GIF and typing animation are shown automatically.
4. On that repository, go to **Actions** and open **Generate contribution snake**. Select **Run workflow**.
5. Wait for the workflow to succeed and for the `output` branch to be created.
6. Edit `README.md`, remove the HTML comment markers (`<!--` and `-->`) around the snake image so the animation appears on your profile. Commit.
7. For future automatic regeneration, leave GitHub Actions enabled. Scheduled workflows can be disabled by GitHub after prolonged repository inactivity.

## Customize
- Rename or reorder the <details> tool sections for areas you actually use; the list is intended as an exploration catalog, not an expertise claim.
- Add verified project URLs once your repositories are ready.
- Verify that external GitHub statistics cards are loading, since third-party widget services can be rate-limited.
- Never commit secrets, private assessment notes, targets or active competition flags.

- `README.md`: complete profile page, project and skills sections, live widgets
- `assets/vyadh-terminal.gif`: original locally hosted looping terminal animation
